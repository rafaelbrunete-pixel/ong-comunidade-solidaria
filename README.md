# 🌟 ONG Comunidade Solidária — SPA Web

Uma aplicação web do tipo **SPA (Single Page Application)** feita com **HTML, CSS e JavaScript puro**. O site simula uma ONG com navegação dinâmica e um formulário de cadastro de voluntários, publicado via **GitHub Pages**.

---

## 🚀 Funcionalidades

- 🧭 **Navegação SPA:** Início, Projetos e Cadastro sem recarregar a página
- 🧩 **Templates dinâmicos:** Conteúdo gerado via JavaScript
- ✅ **Validação de formulário:** Erros exibidos para Nome, E-mail, Telefone e CPF
- ✨ **Visual moderno:** Animações, hover e responsividade básica
- 🌐 **Publicação:** Acesso público pelo GitHub Pages

---

## 🧠 Tecnologias utilizadas

- 🏗️ **HTML5** — estrutura semântica
- 🎨 **CSS3** — estilos, animações e responsividade
- 🧪 **JavaScript** — lógica de SPA sem frameworks
